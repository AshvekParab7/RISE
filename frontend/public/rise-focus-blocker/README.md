# RISE Focus Blocker

This is an unsigned Firefox extension package.

## Local installation

1. Download and extract `rise-focus-blocker.zip`.
2. Open `about:debugging#/runtime/this-firefox` in Firefox.
3. Select **Load Temporary Add-on**.
4. Choose the extracted `manifest.json` file.

Firefox only installs permanently signed add-ons through the normal Add-ons manager. A permanent public release must be signed through addons.mozilla.org.
